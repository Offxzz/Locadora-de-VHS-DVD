# Locadora-de-VHS-DVD
Sistema de gestão para uma locadora de fitas VHS e DVDs, desenvolvido em linguagem C como projeto em grupo da disciplina Algoritmos e Pensamento Computacional.

O programa simula o dia a dia de uma locadora clássica: cadastro de clientes, catálogo de filmes, compra de mídias de fornecedores, locações, devoluções e relatórios. Os dados ficam em memória durante a execução e são gravados em arquivos .csv, então continuam disponíveis na próxima vez que o sistema for aberto.
